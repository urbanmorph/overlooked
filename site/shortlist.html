Shortlists for people who identify

A sample of observations from India on iNaturalist that wait for a name. Each one has a short list of names to check. The most useful observations come first. In groups with species lists, these are the ones that, if the first name is right, give the first record of a species in a state, or a record of a threatened species or a species endemic to India (from our master list). Then come the observations that waited longest.

This is a small sample

This page shows a small part of about 29 lakh observations from India that wait for a name on iNaturalist. For each group, we took up to 1,000 observations uploaded in the last 120 days. Each week we check them on iNaturalist and stop listing those that got a name or were removed. We keep some recent observations back to test the lists, so some groups are small. If the page is useful, we will add more.

Read this first

  • This page tests whether AI can help people identify observations.
  • A model made each list: BioCLIP 2.5, with a classifier that we trained on research-grade photos from India. A list is a suggestion. It is not an identification.
  • Check every name on iNaturalist. Add an identification only when you can see the features in the photos.
  • We post nothing to iNaturalist. The link opens the observation, and you identify it there yourself.
  • Some groups need a specimen or a microscope, for example lichens and many insects. A photo is not always enough. Groups that do not have enough test data are not on this page.
