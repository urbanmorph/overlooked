MCP server for AI assistants

Ask your AI assistant about the species of India. With our MCP server, an assistant such as Claude or ChatGPT reads the same weekly list as this site and gives each answer with its sources. You need no key and no account. The server only reads data.

The address

https://yellide.com/mcp

MCP (Model Context Protocol) is an open standard that lets AI assistants use tools. This server uses Streamable HTTP and needs no authentication. Open this address in a browser and you see this page; an assistant at the same address gets the tools.

Add it to your assistant

Claude
claude.ai and Claude Desktop
Open Settings, then Connectors, then Add custom connector. Name: Overlooked. URL: the address above. Then turn the connector on in a chat.
Claude Code
Run this in a terminal. --scope user adds it for all your projects:
claude mcp add --transport http --scope user overlooked https://yellide.com/mcp
ChatGPT
Turn on developer mode in the settings for apps and connectors. Then create a connector with the address above, and choose no authentication.
Codex
CLI, IDE extension and the ChatGPT desktop app
Run this in a terminal:
codex mcp add overlooked --url https://yellide.com/mcp
Or add this to ~/.codex/config.toml:
[mcp_servers.overlooked]
url = "https://yellide.com/mcp"
VS Code
Install in VS Code
Or add this to .vscode/mcp.json:
{
  "servers": {
    "overlooked": {
      "type": "http",
      "url": "https://yellide.com/mcp"
    }
  }
}
Cursor
Install in Cursor
Or add this to ~/.cursor/mcp.json:
{
  "mcpServers": {
    "overlooked": {
      "url": "https://yellide.com/mcp"
    }
  }
}
Other clients
Windsurf, Zed, JetBrains and more
Open the MCP settings of the client and add a server with these values:
  • Transport: HTTP (Streamable HTTP).
  • URL: https://yellide.com/mcp
  • Authentication: none. No key, no headers.

Use the name of the URL field that your client asks for. Most clients use url; some (Windsurf, for example) use serverUrl. A client can ignore a server with a wrong field name and give no error.

What you can ask

Ask in your own words. The assistant chooses the tool. Some examples, with the tool that answers:

You askTool
What is the IUCN status of the Great Indian Bustard, and in which states does it have records?find_species, get_species
How many threatened birds have an open record in Kerala?count_species
List the threatened snakes of the Western Ghats.list_species
Which species in India are critically endangered?list_species
How many butterfly species are documented from India, and how many have a record since 2016?count_species
Which orchids of Karnataka are not assessed by IUCN?list_species
Which new frog species were described from India since 2025? Give the papers.new_species
Does the king cobra have a DNA barcode from India, and how many records with photos?find_species, get_species

With bharatlas: answers for a place

Add the bharatlas MCP server too, and an assistant can answer for a place, a point or "near me". bharatlas finds the state and the biogeographic province of the place; Overlooked answers for them. The assistant must ask bharatlas locate for the layers lgd_states and biogeographic_zones: the province layer is not in its default list. Our server tells the assistant this.

You askWhat the assistant does
What threatened mammals have records in the region around Bandipur?bharatlas locate on Bandipur: Karnataka, province 5B. Then Overlooked list_species with state Karnataka, region 5B, group mammals, IUCN threatened.
I am in Shillong. How many birds of this region are not assessed by IUCN?bharatlas locate: Meghalaya, province 9B. Then count_species with state Meghalaya, region 9B, group birds, IUCN NE.
What protected areas are near Ooty, and which threatened birds have records in that region?bharatlas nearby on the protected areas layer, then locate. Then list_species.
Which endemic plants of the Western Ghats have records in Kerala?No bharatlas needed: a region name goes straight to list_species.

What these answers mean.

  • They tell what is recorded in the state and the region, not what you will see at the spot. With a state and a region, a species has records in each, not always in the part where they meet.
  • This is not a field guide or a list of sightings. A record shows that a species was found in the area, not that it lives there now or how common it is. For a site, ask the forest department, local naturalists or eBird.
  • To protect species at risk from collection and trade, the answers stop at the state and the province. Do not add finer locations of threatened species from other sources. See Sensitive locations.
  • Each answer gives its credits, the week of the list, and a disclaimer: Overlooked is a monitor of public data, not an authority.

Tools

ToolWhat it gives
find_speciesSpecies that match a Latin or English name, or its start (up to 10), with the key for get_species.
get_speciesOne species in full: the sources that list it, open record, states with an open record, biogeographic regions, IUCN category with the year, DOI and trend of the assessment, endemic mark, year described and authority, family and order, type specimens, photos and DNA barcodes from India, names in Indian languages, a photo with its credit, and the iNaturalist observations that wait for a name.
count_speciesNumbers: documented, with an open record, threatened, recorded in the last 10 years, endemic, and per IUCN category.
list_speciesThe species, 100 to a page, with the total.
new_speciesSpecies described from India since a year (2007 or later): year, group, state of the type locality, journal, a link to the paper, and records since the description.

count_species and list_species take filters, and the filters combine: group (birds, butterflies, orchids...), state, biogeographic region or province, IUCN categories or "threatened", endemic, order, suborder (snakes or lizards), family, open record, recorded since a year, described since a year.

The server also gives four resources: overlooked://about (what the words mean), overlooked://groups, overlooked://states and overlooked://regions (the values the filters accept).

Good to know

  • Every answer gives the week of the list, the licence, the credits of the sources and a disclaimer. Please pass them on with what you publish.
  • To protect species at risk from collection and trade, the server answers by state or biogeographic province only, never by district or point. See Sensitive locations.
  • Overlooked is a monitor of public data, not an authority. For the status of a species, consult BSI, ZSI, the IUCN Red List and the state forest department.
  • A species is in a state when it has an open record placed there. It is in a region when a GBIF record of it is placed there.
  • Regions are the biogeographic zones and provinces of the Wildlife Institute of India: 10 zones and 26 provinces. There is no Eastern Ghats unit: its nearest is 6C, Deccan Peninsula: Eastern Highlands.
  • Endemic marks come only from the sources that give them: Kew for plants, and ZSI and other checklists for some animal groups. Birds, mammals, reptiles, amphibians, fish and butterflies have no marks yet. The answer names these groups.
  • The server does not identify photos, and it posts nothing anywhere.
  • The same data is open as files: see the data guide and Sources and method.

Try it without an assistant

The server answers JSON-RPC over HTTP POST. For developers, this lists the tools:

curl -s https://yellide.com/mcp \
  -H 'content-type: application/json' \
  -d '{"jsonrpc":"2.0","id":1,"method":"tools/list"}'

And this counts the threatened species of the Western Ghats:

curl -s https://yellide.com/mcp \
  -H 'content-type: application/json' \
  -d '{"jsonrpc":"2.0","id":2,"method":"tools/call","params":{"name":"count_species",
       "arguments":{"region":"Western Ghats","iucn":["threatened"]}}}'
